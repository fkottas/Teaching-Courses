# Machine Learning in Finance

## NKUA MPhil in Economics · 2026–2027

Professional student-facing course materials by **Dr. Ferdinantos Kottas**.

This repository is the dedicated e-class for the course. It is intentionally separate from the credit-risk book and from research or teaching-code repositories.

## Start here

1. Open the [2026–2027 course hub](2026-2027/README.md).
2. Read the [13-week course map](2026-2027/syllabus/13_week_course_map.md).
3. Start with [Lecture 0–1](2026-2027/lectures/lecture-00-01/README.md).
4. Download the [Lecture 0–1 presentation](2026-2027/lectures/lecture-00-01/slides/Lecture_00_01_Course_Orientation_and_Python_Foundations_2026-2027.pptx).
5. Open the [executed Colab notebook](2026-2027/lectures/lecture-00-01/notebooks/lecture_00_01_colab.ipynb).

## Repository design

| Area | Purpose |
|---|---|
| `2026-2027/syllabus/` | Official course map, assessment and weekly route |
| `2026-2027/lectures/` | Lecture-by-lecture slides, notebooks and guides |
| `2026-2027/datasets/` | Datasets, provenance and data dictionaries |
| `2026-2027/assignments/` | Weekly Colab and DataCamp exercise instructions |
| `2026-2027/project/` | Capstone routes, deliverables and presentation guidance |
| `2026-2027/reference/` | Mathematics, metrics and reproducibility notes |

The core course follows supervised learning. Unsupervised learning is not part of the core 13-week route.

## Academic source

The course follows the official NKUA curriculum: [Machine Learning in Finance](https://mphil-en.econ.uoa.gr/programme_and_studies/curriculum_for_the_academic_year/machine_learning_in_finance).
