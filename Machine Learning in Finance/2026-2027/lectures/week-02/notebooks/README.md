# Week 2 notebooks

These files are the runnable laboratory for Week 2. Use the executed notebook for the guided class route and the Python script when working locally in Spyder.

| File | Use |
|---|---|
| [Executed Colab notebook](lecture_02_numpy_pandas_eda.ipynb) | Open in Colab, run from top to bottom, and keep the visible outputs |
| [Spyder/local Python script](lecture_02_numpy_pandas_eda.py) | Run the same core examples as a local Python script |

## Data loading

The notebook loads the complete 30,000-row UCI dataset from the course repository as a compressed CSV. It uses pandas.read_csv with compression="gzip", so students do not need to download or unzip the file manually.

## Notebook contents

- NumPy arrays, shapes, indexing, returns, and portfolio weights
- Pandas loading, filtering, grouping, joins, and transformations
- Missingness, duplicate checks, target balance, and data types
- Descriptive statistics, IQR, grouped default rates, and correlations
- Labelled bar and scatter plots
- Interpretation and limitations before supervised modelling

The notebook is saved in standard Jupyter Notebook format with executed outputs. The mathematics guide is kept separately so the PowerPoint remains editable.
