## Scope

This lecture develops the table and array skills needed before supervised learning. It covers NumPy arrays, Pandas DataFrames, indexing, filtering, grouping, joins, transformations, missingness, descriptive statistics, correlations, and exploratory visualisation.

The financial case uses the canonical UCI Default of Credit Card Clients dataset. The observation unit is one borrower credit-card account record. The notebook records the source, variable definitions, units, target coding, and limitations before any model is fitted.
