# Lecture 2 weekly assignment

Use the canonical UCI credit-risk CSV to produce a compact exploratory analysis that a classmate can reproduce.

Required evidence:

1. Source, access date, observation unit, target, and units.
2. Shape, data types, missingness, duplicate rows, and target balance.
3. Descriptive statistics for at least six variables.
4. One groupby or pivot_table comparison with group counts.
5. Two labelled plots and one paragraph interpreting each.
6. One data-quality limitation and one reason the result is not causal.

Submit the Colab notebook one day before the next course meeting. Complete the assigned DataCamp Python practice as part of the weekly work.
