# Week 1 weekly assignment

## Deadline

Submit the completed Colab notebook one day before the next course meeting.

## Task

Use the public Apple price and volume dataset from the lecture notebook. Extend the notebook with:

1. A short financial question written in one paragraph.
2. A data audit covering shape, columns, types, and missingness.
3. Mean, median, standard deviation, and the first three simple returns.
4. Two labelled charts: one distribution chart and one time or relationship chart.
5. A short interpretation that separates what the data show from what they cannot establish.

## Submission standard

The notebook must run from a clean Colab session. Keep the code, output, and interpretation together. Cite the dataset source in the notebook. If AI supported the work, add a short disclosure describing how it was used and verify every generated code cell and claim.
