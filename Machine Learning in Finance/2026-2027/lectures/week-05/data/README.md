# Week 5 data

Lecture date: 25 November 2026 · 15:00–18:00 Greece time (Europe/Athens)

credit_ml_sample.csv is a synthetic, course-sized borrower snapshot used to demonstrate target definition, class balance, preprocessing, regularised logistic regression, calibration, and threshold policy. It is not a production credit dataset and must not be used for lending decisions.

The notebook expects the file at data/credit_ml_sample.csv when run from the package root. The sample has no external-data access requirement, so students can reproduce the lab offline after downloading the package.
