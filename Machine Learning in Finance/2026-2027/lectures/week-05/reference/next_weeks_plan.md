# Week 5–12 course route

The weeks are deliberately separated so that each lecture has one teaching objective and enough time for examples, code, and exercises.

| Week | Focus | Main mathematics and practical work |
| --- | --- | --- |
| 5 | Introduction to machine learning and logistic regression | Learning families, econometrics comparison, data boundaries, sigmoid, odds, likelihood, log-loss, gradient, Ridge/LASSO/Elastic Net, calibration, threshold policy |
| 6 | Model evaluation and calibration | Confusion matrix, precision, recall, F1, ROC-AUC, PR-AUC, log-loss, Brier score, calibration curves, threshold comparison |
| 7 | Decision trees and random forests | Entropy, Gini impurity, information gain, split selection, pruning, bagging, random feature selection, feature importance |
| 8 | Validation and generalisation | Bias–variance, K-fold and nested cross-validation, time-aware validation, learning curves, validation curves, leakage controls |
| 9 | Gradient boosting | Additive models, residual or negative-gradient updates, learning rate, depth, early stopping, XGBoost/LightGBM/CatBoost comparison |
| 10 | Alternative supervised algorithms | K-nearest neighbours, support vector machines, kernels, Naive Bayes, stacking, scaling and decision boundaries |
| 11 | Explainability and monitoring | Calibration, SHAP, permutation importance, partial dependence, feature stability, monthly PSI, target-driven events and bad-rate time series |
| 12 | Neural networks | Layers, weights, biases, activation functions, backpropagation, gradient descent, dropout, regularisation, early stopping, model comparison |

Each deck will be delivered separately for review before the next week is finalised.
