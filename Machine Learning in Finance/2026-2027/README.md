## Assessment

- Weekly exercises, DataCamp practice and Colab submissions: **20%**
- Capstone project: **40%**
- Final examination: **40%**
- Bonus: **up to +10%** for exceptional assignments, project/presentation quality, DataCamp performance, or overall contribution.

## Working rule

Use Google Colab for the laboratories. Run notebooks from top to bottom, keep the output cells, cite every data source, and submit the Colab link or GitHub notebook before the deadline stated in the weekly assignment. The course uses real open data and documents the variables before modelling.
