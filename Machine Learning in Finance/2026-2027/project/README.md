# Capstone Project

The capstone may be completed individually or by a team of two. Choose one supervised-learning route:

- credit-risk prediction;
- fraud-risk prediction;
- stock prediction; or
- portfolio management supported by supervised forecasts.

## Required outputs

1. A reproducible Google Colab notebook or equivalent Python project.
2. Clean code and a documented dataset source.
3. A data dictionary for the variables used.
4. A baseline model and at least one stronger supervised model.
5. Machine-learning metrics and financially meaningful metrics.
6. Validation, limitations, interpretability and practical implications.
7. A concise presentation of the results.

Students may start the project at any point in the semester. Week 13 is reserved for unfinished course material and project presentations.
