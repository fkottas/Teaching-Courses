# Weekly Exercises

Weekly exercises combine a short DataCamp practice route with a Google Colab submission. The Colab submission is due **one day before the next course meeting**, unless the instructor announces a different deadline.

Each submission should contain:

1. the required code;
2. executed outputs and plots;
3. short interpretations in complete sentences;
4. data-source and variable documentation;
5. a final reproducibility check from a clean runtime.

The released Lecture 0–1 package contains the first executed notebook. Later weekly assignment folders will use the same naming and submission convention.
