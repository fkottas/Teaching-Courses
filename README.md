## Assessment

| Component | Weight |
|---|---:|
| Weekly exercises, DataCamp practice, and Colab submissions | 20% |
| Capstone project | 40% |
| Final examination | 40% |
| Bonus for exceptional assignments, project/presentation quality, DataCamp performance, or top overall performance | up to +10% |

The regular assessment totals 100%. The bonus is additional and may raise the final total to 110%.

## Update rule

Each week is a self-contained package. When a lecture is released, its `README.md`, PPTX, Colab, data, data dictionary, and assignment are added inside that week’s folder. Planned weeks already have navigation pages, so the student-facing links do not change and do not lead to 404 pages.
